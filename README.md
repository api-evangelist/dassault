Dassault Systèmes provides the 3DEXPERIENCE platform with thousands of publicly available REST APIs for product design, simulation, and manufacturing industries. The platform covers SolidWorks, CATIA, ENOVIA, and 3D collaboration tools, exposing web services across engineering items, manufacturing processes, CAD collaboration, project tasks, and partner order management through standardized RESTful endpoints.

**Areas:** 3DEXPERIENCE · PLM · CAD · Manufacturing · SolidWorks · CATIA · ENOVIA · Engineering · 3D Collaboration

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Dassault Systèmes: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
